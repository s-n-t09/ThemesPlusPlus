Themes++

A repair-focused continuation of Themes+ for Revenge, Kettu, and compatible Vendetta-based Discord clients. Custom icon packs should load reliably again, with safer caching and theme fallbacks.

Install Themes++

Copy the URL below and add it from your client’s Plugins settings.

https://s-n-t09.github.io/ThemesPlusPlus/install.js
Open installation file
  1. Copy the installation URL above.
  2. Open Discord, then go to Settings → Plugins.
  3. Press the + button to start adding a plugin.
  4. Paste the URL and press Install.
  5. If a confirmation prompt appears, press Confirm.
